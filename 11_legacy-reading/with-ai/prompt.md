# レガシーコード解読プロンプト

以下のプロンプトを Claude Code に投入してください。

---

input/ ディレクトリにある6つのPythonファイル（main.py, proc.py, calc.py, viz.py, util.py, cfg.py）を読んでください。
コメント・docstring・ドキュメントが一切ないレガシーコードです。変数名と関数名が1文字で、セミコロンや三項演算子のネストで1行に圧縮されています。

以下の6項目を日本語で出力してください。

1. 全ファイル・全関数の完全解説
   - 関数ごとに: 現在の名前 → 推定される本来の目的
   - 各引数の意味と型
   - 戻り値の内容と構造
   - cfg.pyの全変数の意味（未使用のものは明示）

2. パイプライン全体のデータフロー図（Mermaid形式 flowchart TD）
   - main.py の run() を起点に、どの関数がどの順で呼ばれるか
   - データがどう変換されていくか
   - 入力ファイルと出力ファイルの関係

3. リネーム提案の対応表
   - ファイル名、関数名、変数名のすべてについて
   - 「現在の名前 → 提案する名前」の表形式
   - 引数名も含む

4. コード品質の問題点
   - 可読性、保守性、バグリスクの3観点で分類
   - 各問題に対する具体的な改善案を添える

5. 技術的負債とリスク
   - デッドコード（未使用変数・未使用関数）の特定と経緯の推測
   - エラーハンドリングの不備箇所
   - テスト容易性の問題
   - 運用リスク

6. 改善提案の優先度付きロードマップ
   - 高/中/低の3段階で分類
   - 工数の目安と期待効果を添える
