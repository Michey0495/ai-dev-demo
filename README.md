# AI開発デモ集 (14AIdevDemo)

従来の開発がAIでどう変わるかを体験するハンズオンデモ集。
12テーマ、各15-20分、Claude Code中心。

## テーマ一覧

| # | テーマ | Before | With AI | 体感差 |
|---|--------|--------|---------|--------|
| 01 | 要求分析 | 手動抽出で漏れ多発 | 150行→構造化文書30秒 | 暗黙要件の自動検出 |
| 02 | DB設計 | 正規化不足・命名バラバラ | 第三正規形+ER図が即時 | アンチパターン自動回避 |
| 03 | API設計 | REST原則違反 | OpenAPI 3.0+型定義 | 設計と型が同時生成 |
| 04 | UIプロトタイプ | デザイン崩れ | Tailwindレスポンシブ | 見た目の差が圧倒的 |
| 05 | CRUD実装 | 空スケルトン | Zod検証付き完全CRUD | 数十秒で動くAPI |
| 06 | テスト生成 | 正常系5ケース | 境界値含む60-80ケース | エッジケース自動発見 |
| 07 | コードレビュー | 命名指摘のみ | 競合状態/XSS全件検出 | 致命バグをAIが拾う |
| 08 | セキュリティ診断 | 10個中6個検出 | 全10件+CWE+修正コード | 検出率100% vs 60% |
| 09 | デバッグ | 2時間+誤仮説2回 | 30秒で根本原因特定 | 2時間 vs 30秒 |
| 10 | リファクタリング | 途中で壊れた | 型安全な小関数群+テスト | 200行→8-10関数 |
| 11 | レガシー解読 | 1日がかりの推測メモ | 全関数解説+データフロー図 | 丸1日 vs 30秒 |
| 12 | ドキュメント生成 | 週末返上の不完全版 | 5種類を1プロンプトで | 5文書が同時生成 |

## 使い方

1. テーマフォルダを開く
2. README.md でBefore/Afterの概要を把握
3. input/ のデータを確認
4. before/ で従来手法の限界を体感
5. with-ai/prompt.md をClaude Codeに投入
6. expected-output/ と比較して効果を確認

## フォルダ構成（各テーマ共通）

```
XX_theme-name/
  README.md               テーマ説明・手順
  input/                  入力データ
  before/                 従来手法の成果物（意図的に不完全）
  with-ai/prompt.md       Claude Code用プロンプト
  expected-output/        AI生成の模範回答
```
