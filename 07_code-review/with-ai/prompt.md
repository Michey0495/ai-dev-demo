# コードレビュー プロンプト

以下のdiffを本番リリース前のコードレビューとして精査してください。

対象ファイル: `./input/cart-feature.diff`

## レビュー観点（優先度順）

1. セキュリティ
   - XSS, SQLi, SSRF, 認証・認可の不備
   - ユーザー入力のバリデーション漏れ
   - デバッグ用コードや機密情報の残留
2. 並行性・データ整合性
   - 競合状態（TOCTOU, Lost Update）
   - トランザクション境界の妥当性
3. パフォーマンス
   - N+1クエリ、不要な再取得
   - メモリ使用量（上限なしの全件取得等）
4. 型安全性
   - any型の使用箇所と修正方法
   - null/undefined の未チェックアクセス
5. 保守性
   - デッドコード、命名、マジックナンバー

## 出力形式

各指摘を以下のフォーマットで出力:

- カテゴリ別にグループ化
- 重要度: Critical / Warning / Info
- CWE番号を付与（該当するものがあれば）
- ファイル名と行番号を明記
- 問題のコードを引用
- 攻撃シナリオまたは障害シナリオを具体的に記述
- 修正後のコードスニペットを提示
- 末尾に重要度別の検出件数サマリーテーブル
