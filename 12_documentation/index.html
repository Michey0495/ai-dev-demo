## 認証

認証が必要なエンドポイントでは、
リクエストヘッダーにJWTアクセストークンを含める。

```
Authorization: Bearer <access_token>
```

アクセストークンの有効期限はデフォルトで15分。
リフレッシュトークンの有効期限は7日間。

## レート制限

/api/ 配下の全エンドポイントに適用。
- ウィンドウ: 15分（デフォルト）
- 最大リクエスト数: 100回/ウィンドウ

---

## POST /api/auth/register

新規ユーザーを登録し、トークンペアを返す。

リクエスト:
```json
{
  "email": "user@example.com",
  "password": "securePassword123",
  "name": "山田太郎"
}
```

バリデーション:
- email: 有効なメールアドレス形式（必須）
- password: 8文字以上128文字以下（必須）
- name: 1文字以上100文字以下（必須）

レスポンス: 201 Created
```json
{
  "user": {
    "id": "clxyz1234567890",
    "email": "user@example.com",
    "name": "山田太郎",
    "role": "customer"
  },
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
}
```

エラー:
- 400: メールアドレスが既に登録されている
- 400: バリデーションエラー

## POST /api/orders

注文作成。認証が必要。
トランザクション内で以下を一括実行:
- 全商品の存在確認
- 在庫の充足確認
- クーポンの有効性チェック
- 税額計算（デフォルト10%）
- 送料計算（重量ベース、閾値以上で無料）
- 注文レコード作成と在庫減算

リクエスト:
```json
{
  "items": [
    { "productId": "prod_abc123", "quantity": 2 },
    { "productId": "prod_def456", "quantity": 1 }
  ],
  "shippingAddress": "東京都渋谷区...",
  "couponCode": "SPRING2026"
}
```

レスポンス: 201 Created
```json
{
  "id": "order_xyz789",
  "status": "pending",
  "subtotal": 6400,
  "tax": 640,
  "shippingFee": 0,
  "discount": 0,
  "totalAmount": 7040,
  "items": [...]
}
```

# EC商品管理API

商品カタログ、注文処理、カテゴリ管理を提供するREST API。
JWT認証とロールベースのアクセス制御、
注文のステータス遷移管理、在庫の自動減算、
税計算と送料計算を備える。

## 技術スタック

| 分類 | 技術 |
|------|------|
| ランタイム | Node.js |
| 言語 | TypeScript |
| フレームワーク | Express |
| ORM | Prisma |
| バリデーション | Zod |
| 認証 | JSON Web Token (jsonwebtoken) |
| パスワードハッシュ | bcryptjs |
| セキュリティ | helmet, cors, express-rate-limit |

## セットアップ

```bash
git clone <repository-url>
cd <project-directory>
npm install
cp .env.example .env
npx prisma migrate dev
npm run dev
```

## ディレクトリ構成

```
src/
  server.ts          エントリーポイント。helmet, cors,
                     rate-limit, logger登録。
  routes/
    index.ts         4リソースのルーター登録
    products.ts      商品CRUD。検索、価格帯フィルタ、
                     ソート対応。admin限定。
    orders.ts        注文管理。税計算、送料、クーポン。
                     トランザクション内で在庫減算。
    auth.ts          認証4エンドポイント。JWT発行。
    categories.ts    カテゴリCRUD。階層構造対応。
  middleware/
    auth.ts          JWT認証 + ロールベースアクセス制御
    validation.ts    Zodバリデーション（body + query）
    logger.ts        構造化JSONリクエストログ
  db/
    prisma.ts        Prismaシングルトン + 接続チェック
  utils/
    errors.ts        カスタムエラー5種 + エラーコード
    tax.ts           税額・送料計算ユーティリティ
  types/
    index.ts         共有型定義
```
# アーキテクチャ概要

Express + Prisma による3層構成のREST API。
ルーティング層、ミドルウェア層、データアクセス層に分離し、
ロールベースのアクセス制御と構造化ログを備える。

```bash
npm ci
```

## Dockerfile（マルチステージ）

```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY prisma ./prisma
RUN npx prisma generate
COPY tsconfig.json ./
COPY src ./src
RUN npx tsc

FROM node:18-alpine AS runner
WORKDIR /app
RUN addgroup --system --gid 1001 appgroup && \
    adduser --system --uid 1001 appuser
COPY package.json package-lock.json ./
RUN npm ci --production
COPY --from=builder /app/node_modules/.prisma ./node_modules/.prisma
COPY --from=builder /app/dist ./dist
COPY prisma ./prisma
USER appuser
EXPOSE 4000
HEALTHCHECK --interval=30s --timeout=5s \
    CMD wget --spider http://localhost:4000/health || exit 1
CMD ["node", "dist/server.js"]
```
