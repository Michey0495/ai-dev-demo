# TaskFlow -- タスク管理アプリ 機能仕様書

バージョン: 1.0
最終更新: 2026-03-20
作成者: プロダクト企画部

## 製品概要

TaskFlow はチーム向けのタスク管理ツール。
プロジェクト単位でタスクを整理し、メンバーへの割り当て、進捗追跡、ラベルによる分類を行う。
初期リリースではWebアプリのバックエンドAPIを構築する。

## ユーザーと権限

システムには3種類のロールが存在する。

- オーナー: 全操作が可能。プロジェクトの作成・削除、メンバー招待を行える
- メンバー: タスクのCRUD、ラベル管理、自身へのタスク割り当てが可能
- ゲスト: タスクとプロジェクトの閲覧のみ可能

ユーザーはメールアドレスとパスワードで認証する。
ログイン後にアクセストークンを発行し、以降のリクエストに添付する。

## プロジェクト

プロジェクトはタスクをまとめる最上位の単位。

属性:
- プロジェクト名（必須、100文字以内）
- 説明文（任意、1000文字以内）
- ステータス: active / archived
- 作成日時
- 更新日時

操作:
- プロジェクトの一覧取得（自分が参加しているもの）
- プロジェクトの詳細取得
- プロジェクトの新規作成（オーナーのみ）
- プロジェクトの情報更新（オーナーのみ）
- プロジェクトのアーカイブ（オーナーのみ）
- プロジェクトへのメンバー追加・削除（オーナーのみ）
- プロジェクトのメンバー一覧取得

## タスク

タスクはプロジェクトに所属する作業単位。

属性:
- タイトル（必須、200文字以内）
- 説明文（任意、5000文字以内、Markdown対応）
- ステータス: todo / in_progress / in_review / done / cancelled
- 優先度: low / medium / high / urgent
- 担当者（任意、1名）
- ラベル（任意、複数可）
- 期限日（任意）
- 作成者
- 作成日時
- 更新日時

ステータス遷移ルール:
- todo -> in_progress, cancelled
- in_progress -> in_review, todo, cancelled
- in_review -> done, in_progress
- done -> in_progress（差し戻し）
- cancelled -> todo（復活）

操作:
- タスク一覧取得（プロジェクト内、フィルタ・ソート対応）
- タスク詳細取得
- タスク新規作成（メンバー以上）
- タスク情報更新（メンバー以上）
- タスクのステータス変更（メンバー以上、遷移ルールに従う）
- タスクの担当者変更（メンバー以上）
- タスクへのラベル付与・解除（メンバー以上）
- タスク削除（オーナーのみ）

フィルタ条件:
- ステータスで絞り込み（複数指定可）
- 優先度で絞り込み
- 担当者で絞り込み
- ラベルで絞り込み（複数指定可、AND条件）
- 期限日の範囲指定
- キーワード検索（タイトルと説明文を対象）

ソート:
- 作成日時（デフォルト、降順）
- 更新日時
- 期限日
- 優先度

## ラベル

ラベルはタスクを分類するためのタグ。プロジェクトごとに管理する。

属性:
- ラベル名（必須、50文字以内）
- カラーコード（必須、HEX形式）
- 作成日時

操作:
- ラベル一覧取得（プロジェクト内）
- ラベル新規作成（メンバー以上）
- ラベル情報更新（メンバー以上）
- ラベル削除（オーナーのみ。紐づくタスクからも解除される）

## コメント

タスクにはコメントを投稿できる。

属性:
- 本文（必須、2000文字以内、Markdown対応）
- 投稿者
- 投稿日時
- 更新日時

操作:
- コメント一覧取得（タスク内、時系列順）
- コメント投稿（ゲスト以上）
- コメント編集（投稿者本人のみ）
- コメント削除（投稿者本人またはオーナー）

## 非機能要件

- APIレスポンスタイムは95パーセンタイルで200ms以下
- 一覧取得は必ずページネーション対応（1ページあたりのデフォルトは20件、最大100件）
- レートリミット: 認証済みユーザーは1000リクエスト/分、未認証は100リクエスト/分
- 全レスポンスはJSON形式
- 日時はISO 8601形式（UTC）
- IDはUUID v4
