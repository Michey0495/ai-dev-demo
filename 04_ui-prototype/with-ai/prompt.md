# AI Coding Agent向け プロンプトテンプレート

`input/wireframe.md` の内容を添付した上で、以下のプロンプトを投げる。

---

## プロンプト本文

```
添付したワイヤーフレーム（wireframe.md）をもとに、ブラウザで直接開ける単一HTMLファイルとして
営業ダッシュボードのUIプロトタイプを作成してください。

## 技術要件

- Tailwind CSS v3をCDN経由で読み込む（他の外部依存なし）
- 単一HTMLファイルで完結させる
- セマンティックHTML: header, nav, main, aside, section, footer を適切に使う
- アクセシビリティ: 主要なランドマークにaria-label属性を付与する

## レスポンシブ 3段階

| 段階 | 幅 | サイドバー | KPIカード | テーブル |
|------|-----|-----------|----------|---------|
| モバイル | 〜767px | 非表示 | 1列 | 横スクロール |
| タブレット | 768px〜1023px | 非表示 | 2列 | 横スクロール |
| デスクトップ | 1024px〜 | 常時表示（左240px） | 4列 | 全幅表示 |

## 配色ルール（厳守）

使える色はネイビー系とウォームグレー系の2系統のみ。

- ネイビー基調: #1e3a5f（メイン）、濃淡は #091626〜#eef2f7 の範囲
- ウォームグレー: #6b7280（テキスト補助）、#f9fafb / #f3f4f6（背景）
- 背景は白系（#ffffff または #f9fafb）
- 状態バッジの区別は、ネイビーの濃淡とグレーの濃淡で表現する
- 緑・オレンジ・赤のような多色は一切使わない
- 絵文字は一切使わない

## ダークモード

- html要素に class="dark" を付与して切替える方式（Tailwind darkMode: 'class'）
- ヘッダー右にトグルボタンを配置する
- OS設定（prefers-color-scheme）を初期値として読み込む
- ダーク時の背景は #091626〜#102239、カードは #172e4c、テキストは #d4dde8

## グラフエリア

- CSSとインラインSVGのみで折れ線グラフを描画する（Chart.js等は不要）
- 6つのデータポイント（10月〜3月）を打ち、polylineで接続する
- 各データポイントにホバーで金額を表示するツールチップを実装する
- ツールチップはSVG内の rect + text で構成し、JSでopacityを切替える
- タッチデバイスでもタップで表示されるようにする

## テーブル機能

- 列ヘッダーをクリックすると昇順/降順でソートできる（vanilla JS）
- 金額列は数値としてソートする（data-raw属性に数値を持たせる）
- 日付列はISO形式の data-raw属性でソートする
- ソート中の列ヘッダーに視覚的なフィードバックを入れる

## コンテンツ

- ワイヤーフレームに記載されたサンプルデータをそのまま使用する
- テキストは全て日本語
- 日付や金額のフォーマットは日本式（¥記号、yyyy/mm/dd）
```

---

## このプロンプトの設計意図

曖昧さの排除が最優先。「きれいなデザインで」では出力が安定しない。

配色を16進数で指定し、ブレイクポイントをピクセル値で区切り、ダークモードの切替方式まで指定している理由は、AIが勝手に判断する余地を減らすため。判断の余地が多いほど、出力のブレ幅が大きくなる。

ワイヤーフレームとプロンプトを分離している構成にも意味がある。同じワイヤーフレームに対して配色やインタラクションの指示だけ差し替えれば、別バリエーションをすぐ試せる。デザイン方針がコードに直接埋め込まれず、プロンプト側で制御できる状態が理想。

テーブルソートやグラフツールチップのような動的機能を要求に含めているのは、「見た目だけのモックアップ」から「触って検証できるプロトタイプ」に引き上げるため。プロダクトマネージャーやデザイナーがブラウザで操作して、データの見せ方にフィードバックを返せるレベルが目標になる。
