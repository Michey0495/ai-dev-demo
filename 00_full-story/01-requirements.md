# TeamTalk -- 社内チャットアプリ 要件定義書

バージョン: 1.0
作成日: 2026-03-29
ステータス: ドラフト（AI生成 → 人間レビュー待ち）


## 1. プロジェクト概要

社内コミュニケーションを一元化するチャットアプリケーション。SlackやTeamsの代替ではなく、社内に閉じたセキュアな環境でのリアルタイムコミュニケーションを実現する。従業員500名規模の企業を想定。


## 2. ユーザーと役割

| 役割 | 権限 |
|------|------|
| 管理者 | ユーザー管理、チャンネル管理、監査ログ閲覧、システム設定 |
| 一般ユーザー | メッセージ送受信、チャンネル参加/退出、ファイル添付、プロフィール編集 |
| ゲスト | 招待されたチャンネルのみ閲覧・投稿可能、ファイルアップロード不可 |


## 3. 機能要件

### 3.1 ユーザー管理

- メールアドレスとパスワードによる認証
- SAML/OIDC連携によるSSO対応
- プロフィール（表示名、アバター、ステータスメッセージ）
- オンライン/オフライン/離席のプレゼンス表示
- パスワードリセット（メールベース）

### 3.2 チャンネル

- パブリックチャンネル（全員参加可能）
- プライベートチャンネル（招待制）
- ダイレクトメッセージ（1対1）
- グループDM（2-8名）
- チャンネルのアーカイブと復元
- チャンネル説明文とピン留めメッセージ

### 3.3 メッセージング

- テキストメッセージの送受信
- Markdown記法のサポート（太字、イタリック、コードブロック、リスト）
- メッセージの編集と削除（送信後5分以内）
- スレッド返信
- メンション（@ユーザー名、@channel、@here）
- リアクション（カスタム絵文字セット）
- 未読管理とバッジ表示

### 3.4 ファイル添付

- 画像、PDF、Office文書、テキストファイルのアップロード
- 1ファイルあたり最大50MB
- 画像のインラインプレビュー
- ファイル一覧の検索

### 3.5 検索

- メッセージ全文検索
- フィルター（チャンネル、投稿者、日付範囲）
- ファイル名検索


## 4. 非機能要件

### 4.1 パフォーマンス

- メッセージ送信から表示まで200ms以内（同一リージョン）
- 同時接続500ユーザーを処理可能
- メッセージ検索のレスポンス: 1秒以内（100万件規模）
- ページロード: 初回3秒以内、以降1秒以内

### 4.2 可用性

- 稼働率99.9%（月間ダウンタイム43分以内）
- 計画メンテナンスは月1回、深夜帯に実施
- データバックアップ: 日次（30日保持）

### 4.3 セキュリティ

- 通信の暗号化（TLS 1.3）
- パスワードのハッシュ化（bcrypt、コスト12）
- JWTトークンによるセッション管理（有効期限24時間、リフレッシュトークン7日）
- レート制限（API: 100リクエスト/分/ユーザー）
- 監査ログ（ログイン、チャンネル作成/削除、管理操作）
- ファイルアップロード時のウイルススキャン

### 4.4 技術スタック

- フロントエンド: React + TypeScript + Tailwind CSS
- バックエンド: Hono (TypeScript) on Cloudflare Workers
- データベース: PostgreSQL 16
- リアルタイム通信: WebSocket (Durable Objects)
- ファイルストレージ: R2 (S3互換)
- 検索: PostgreSQL全文検索（初期）→ 将来的にElasticsearch移行


## 5. 画面一覧

| 画面 | 概要 |
|------|------|
| ログイン | メール+パスワード、SSO選択 |
| チャンネル一覧 | サイドバーに表示、未読バッジ付き |
| チャットメイン | メッセージタイムライン、入力欄、スレッドパネル |
| チャンネル設定 | メンバー管理、説明編集、ピン留め一覧 |
| ユーザー設定 | プロフィール編集、通知設定、テーマ切替 |
| 管理画面 | ユーザー一覧、チャンネル管理、監査ログ |
| 検索結果 | メッセージ/ファイルの横断検索結果 |


## 6. 対象外（v1スコープ外）

- 音声通話、ビデオ通話
- 画面共有
- 外部サービス連携（Webhook、Bot API）
- モバイルネイティブアプリ（PWAで対応）
- メッセージの自動翻訳
- E2E暗号化（サーバーサイド暗号化で初期対応）
